How it works

The adapter is the only new service. It translates API calls into Kubernetes objects; the BNK controller programs TMM. The console and API are not in the request path.

Newbnk-inference-adapterthis chart

BNKCNE controllercompiles, pushes over gRPC
Data planeTMMiRule policies, Endpoint Picker, GPU

Every policy runs in TMM in a single pass. The Endpoint Picker chooses the GPU; TMM forwards the request.

    G-->>TMM: allowed

Both contracts follow Lambda Cloud API v1.10.0 conventions: Bearer keys, {"data": ...} and {"error": {...}} envelopes, and -operations paths for actions.

Install

Prerequisites: BNK 2.4 with the Gateway API and Inference Extension CRDs; the endpoint namespace listed in CNEInstance.spec.eppNamespaces and holding the F5 registry pull secret; model-server pods labelled lambda.ai/instance and lambda.ai/role.

helm install bnk-inference-adapter ./chart -n lambda-ie \
  --set config.AUTH_INTROSPECT_URL=http://<your key service>/introspect \
  --set config.USAGE_COLLECTOR_ADDR=<adapter service ip>:5514

The key service has a single contract:

POST /introspect  {"token": "<key>"}
→ 200 {"active": true, "sub": "<user>", "role": "admin"|"member"}   or   200 {"active": false}

See it running in the lab

The reference lab runs this integration on a live BNK 2.4 cluster with NVIDIA GPUs and a replica of the Lambda console. The final challenge, 07 · How Lambda would ship this, is the integration view: contracts, chart values, the generated iRule and the BNK objects behind a live endpoint.

  1. Start the track and wait until the sandbox has finished setting up.
  2. Select Skip on each challenge until you reach challenge 07. Skipping completes each challenge's steps automatically, so the endpoint used in challenge 07 is created along the way.
  3. In challenge 07, use the Lambda Console tab (Inference Gateway → Adopt), the Topology tab and the terminal commands in the challenge text.

If no GPU is available when the sandbox starts, the lab uses clearly labelled simulated instances. Challenge 07 covers the integration, so it works the same either way.
